# Bewerbungsdossier — application packet

Drop the PDFs for your rental application here. The outreach workflow attaches
everything in this folder **only after a landlord replies** — never on first
contact (first contact just says "Dossier auf Anfrage").

## Recommended contents (typical Zürich application)
- [ ] **Ausweis** — passport / ID (or residence permit, Ausweis B/C) PDF
- [ ] **Betreibungsauszug** — debt-collection extract, < 3 months old
      (order at betreibungsschalter.ch or your Betreibungsamt)
- [ ] **Lohnnachweise** — last 3 payslips, or employment contract
- [ ] **Arbeitsvertrag / Anstellungsbestätigung** — proof of employment
- [ ] **Referenz vom aktuellen Vermieter** — reference from current landlord (optional but strong)
- [ ] **Haftpflicht-/Hausratversicherung** — liability insurance proof (optional)
- [ ] **Kurzes Bewerbungsschreiben / Selbstauskunft** — one-page cover sheet (optional)

## Tips
- One combined PDF is fine, or separate files — both attach cleanly.
- Keep names clear, e.g. `01_Ausweis.pdf`, `02_Betreibungsauszug.pdf`.
- Refresh the Betreibungsauszug every few months so it stays < 3 months old.

_This folder is empty by design until you add your documents._
